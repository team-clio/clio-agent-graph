Findings

성공과 함께 드러난 개선점

1

Snapshot 계약 작동

Knowledge, Tool 응답, citation이 동일 SHA에 묶여 branch 이동 영향을 받지 않는다.

2

Agent 탐색 비용

분석 124.145초. tool-call budget, 중복 path cache와 relevance stopping rule이 필요하다.

3

Seed query 개선

긴 exact grep 대신 symbol/token 분해나 trigram 코드 검색이 필요하다.

4

분류 Guardrail

코드에서 domain_rule도 생성됐다. repository topic 유형 정책을 명시할 필요가 있다.

5

Replay 효과

47.685초 작업이 0.101초로 줄었고 LLM 호출과 revision 증가를 생략했다.

6

운영 관측성

tool name·latency·result count·snapshot만 표준 trace로 남기면 민감정보 없이 진단 가능하다.
