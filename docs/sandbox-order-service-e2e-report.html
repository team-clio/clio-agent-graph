사례별 관측

Issue 1 · strongest

Pagination offset

의도한 결함: offset = page * size로 1-based page 1에서 첫 두 항목을 건너뜁니다.

Agent 가설: 정상식 (page - 1) * size가 필요하다고 한국어로 설명하고, boundary condition을 포함한 수정·회귀 test plan을 만들었습니다.

Issue 2 · highest confidence

Coupon percentage scale

의도한 결함: percent를 100이 아닌 10으로 나눠 100 × 15%가 -50이 됩니다.

Agent 반응: Decimal("10") → Decimal("100")으로 나눠야 한다고 정확히 지목하고, 85.00 기대값까지 수치로 검증했습니다.

Issue 3 · concurrency

Inventory reservation race

의도한 결함: 재고 확인과 감소가 분리되어 병렬 요청이 재고를 음수로 만듭니다.

Agent 가설: check-then-act race condition과 원자적 reserve 또는 lock/transaction 필요성을 제시했습니다.

Issue 4 · time handling

UTC session expiry

의도한 결함: aware expires_at를 naive datetime.now()와 비교합니다.

Agent 가설: timezone-aware now 사용으로 통일하라는 정확한 해결 방향을 한국어로 생성했습니다.

Issue 5 · security

Webhook timing leak

의도한 결함: HMAC digest를 직접 == 비교합니다.

Agent 반응: hmac.compare_digest로 constant-time 비교를 수행해야 한다고 지적했지만, 동시에 "소스가 이미 교정된 게 아닌가"라는 오탐 가능성 가설도 함께 제기해 confidence가 가장 낮습니다.
